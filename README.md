# Pump Plan

Mobile-friendly website for a postpartum **pumping + eating** week plan.

- Nested tabs: **Year → Month → Day**
- **Best Day** tab (best-set / PR vibe) from logged pumps & plates
- Fixed **24h clock** (pie); only gold meal slices change by day
- Content seeded from the household PDF guide — **not medical advice**

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Static `dist/` output works on GitHub Pages, Netlify, Vercel, or Cloudflare Pages.
Push this folder to `https://github.com/n2i0g-322/Pump-plan` when ready.

## iPhone

Safari → Share → **Add to Home Screen** (PWA meta + manifest included).
